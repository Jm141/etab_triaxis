# Installation & Setup

This directory contains installation, setup, and configuration guides.

## Available Guides

- **[Install](./INSTALL.md)**  
  Main installation guide for the Tabulation System.

- **[Install Database](./INSTALL_DATABASE.md)**  
  Database setup and configuration instructions.

- **[Migration Guide](./MIGRATION_GUIDE.md)**  
  Guide for running database migrations.

- **[Quick Start](./QUICK_START.md)**

- **[CDN to Local Summary](./CDN_TO_LOCAL_SUMMARY.md)**

- **[Local Resources Guide](./LOCAL_RESOURCES_GUIDE.md)**  
  Guide for managing local resources and assets.

## Installation Steps

1. Follow the [Install](./INSTALL.md) guide for basic setup
2. Set up the database using [Install Database](./INSTALL_DATABASE.md)
3. Run migrations using [Migration Guide](./MIGRATION_GUIDE.md)
4. For quick setup, see [Quick Start](./QUICK_START.md)
