## Key Concepts

- **Raw Scores**: Scores entered by judges (0 to max_score)
- **Weighted Scores**: Raw scores multiplied by criteria weight
- **Total Score**: Sum of all weighted scores for a contestant
- **Average Score**: Average of total scores across all judges
- **Ranking**: Based on average weighted scores
