This directory contains guides for importing data into the system.

## Available Guides

- **[CSV Import Guide](./CSV_IMPORT_GUIDE.md)**  
  Guide for importing data via CSV files.

- **[Judge CSV Import Guide](./JUDGE_CSV_IMPORT_GUIDE.md)**

- **Contestants**: Import contestant data
