## Report Types

- **Per Round Report**: Scores and rankings for a specific round
- **Per Level Report**: Aggregated scores for a level (all rounds)
- **Per Judge Report**: All scores submitted by a specific judge
- **Finals Report**: Final rankings with all round scores
