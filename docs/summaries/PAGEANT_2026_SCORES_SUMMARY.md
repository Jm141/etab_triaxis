## Manual Calculation Guide

### Formula:
For each criterion:
```
Weighted Score = Raw Score × (Weight / 100)
```

Total Weighted Score = Sum of all Weighted Scores

### Example:
If a contestant receives:
- Criterion 1: Raw Score = 8.5, Weight = 30%
- Criterion 2: Raw Score = 7.0, Weight = 40%
- Criterion 3: Raw Score = 9.0, Weight = 30%
