# User Guides

  Complete guide for technical admins on how to edit scores, including permission requests and organizer keys.

- **[How to Deduct and Update Scores](./HOW_TO_DEDUCT_AND_UPDATE_SCORES.md)**  
  Comprehensive guide covering both score updates and point deductions, with permission workflows.

- **[How to Update Scores (Tech Admin)](./HOW_TO_UPDATE_SCORES_TECH_ADMIN.md)**

- **[How to Apply Point Deduction](./HOW_TO_APPLY_POINT_DEDUCTION.md)**

### For Judges
